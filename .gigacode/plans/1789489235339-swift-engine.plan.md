# План обновления Weather-вкладки

## Требования
1. Реальный API: `https://api.weather.gov/gridpoints/TOP/32,81/forecast`
2. Запрос каждые 5 секунд **только** когда пользователь на вкладке Weather
3. При уходе с вкладки:
   - Отменить текущий запрос
   - Удалить запрос из очереди
4. Формат вывода: `(иконка) Сегодня - 61F`

### 3. Создать WeatherApiRequest

**Файл:** `Assets/Scripts/Game/Weather/WeatherApiRequest.cs`

Реализация запроса к API:
```csharp
public class WeatherApiRequest : IQueuedRequest<List<WeatherData>>
{
    private readonly string _url = "https://api.weather.gov/gridpoints/TOP/32,81/forecast";
    private readonly WeatherModel _weatherModel;

    public string Id => "WeatherApiRequest";

    public async UniTask<List<WeatherData>> Execute(CancellationToken cancellationToken = default)
    {
        using var request = UnityWebRequest.Get(_url);
        var operation = request.SendWebRequest();

        // Отслеживание отмены
        while (!operation.isDone && !cancellationToken.IsCancellationRequested)
        {
            await UniTask.Yield();
        }

        if (cancellationToken.IsCancellationRequested)
        {
            request.Abort();
            throw new OperationCanceledException();
        }

        if (request.result != UnityWebRequest.Result.Success)
            throw new Exception($"Weather API error: {request.error}");

        var response = JsonUtility.FromJson<WeatherForecastResponse>(request.downloadHandler.text);
        return ParseForecast(response);
    }
}
```

### 4. Обновить WeatherPresenter

**Файл:** `Assets/Scripts/Game/Weather/Presenter/WeatherPresenter.cs`

Изменения:
- Добавить `CancellationTokenSource` для отмены
- Метод `StartWeatherLoop()` — цикл каждые 5 секунд
- При `OnDisable()` — отмена токена и очистка очереди
- При `OnEnable()` — запуск цикла
- Использовать `WeatherApiRequest` вместо `StubWeatherRequest`
- Передавать `CancellationToken` в запрос

```csharp
public class WeatherPresenter : MonoBehaviour, IInitializable
{
    [SerializeField] private WeatherView _view;

    [Inject] private RequestQueue _requestQueue;
    [Inject] private WeatherModel _weatherModel;

    private CancellationTokenSource _cancellationTokenSource;
    private bool _isTabActive;

    public void Initialize()
    {
        _weatherModel.OnDataLoaded += OnWeatherDataLoaded;
        _isTabActive = true;
        StartWeatherLoop();
    }

    private void OnDisable()
    {
        _isTabActive = false;
        _cancellationTokenSource?.Cancel();
        _cancellationTokenSource?.Dispose();
        _requestQueue.CancelRequest("WeatherApiRequest");
    }

    private async void StartWeatherLoop()
    {
        while (_isTabActive)
        {
            await UniTask.Delay(TimeSpan.FromSeconds(5));
            if (!_isTabActive) break;
            LoadWeatherData();
        }
    }

    private void LoadWeatherData()
    {
        _cancellationTokenSource = new CancellationTokenSource();
        var request = new WeatherApiRequest(_weatherModel);
        _requestQueue.Enqueue(request,
            onComplete: () => {},
            onError: (ex) => Debug.LogError($"Weather request failed: {ex.Message}"));
    }

    private void OnWeatherDataLoaded()
    {
        _view.Clear();
        foreach (var data in _weatherModel.GetData())
        {
            _view.AddWeatherCard(data.Icon, data.TemperatureF);
        }
        _view.Show();
    }
}
```
